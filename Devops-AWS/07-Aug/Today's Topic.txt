S3(Simple Storage Service)::
----------------------------
- It is a AWS storage that store and retrieve data/file over the internet .

	Important Terms of S3 ::
	------------------------
		1. S3 Bucket :: A container where objects(like, file, images, videos, logs,...) are store
		2. S3 Object :: An actual file that store in S3 Bucket . 
		3. S3 Object Key :: The key path/name that identify about specific object.

	Important Features of S3 ::
	---------------------------
		1. Scalable :: size of a bucket or storage automatically expand demand on file size 
		2. Highly Durable :: It is capable for store extreme amount of objects 
		3. Versioning :: it store multiple versions of a same file
		4. Life Cycle Policies :: automatically move or delete object by rules.
		5. Access Control :: this can access by a proper authorized person on rules.
			like :: IAM policy, bucket Policy, Access Policy, Encryption
	
	S3 Storage CLASS ::
	------------------
	Storage Class			Typical Use
	------------			------------
	S3 Standard			Frequently accessed data
	S3 Intelligent-Tiering		Unknown/changing access patterns
	S3 Standard-IA			Infrequently accessed data
	S3 One Zone-IA			Infrequently accessed, re-creatable data
	S3 Glacier Instant Retrieval	Archive data needing fast retrieval
	S3 Glacier Flexible Retrieval	Long-term archive
	S3 Glacier Deep Archive		Very long-term, rarely accessed archive

	- Internet Gateway is provide internet connection to the resource under public subents in VPC, while NAT(Network Address Translation) gateway allows to private subnet to initiate unbound internet connection without exposing those resources directly to the internet. The NAT gateway itself placed at public subnet and uses the internet connection through internet gateway.
