3. Run level :: Define the state or operating mode of the system.

Runlevel	Meaning
0	        Shutdown the system
1	        Single-user mode (Maintenance/Rescue mode)
2	        Multi-user mode (varies by distribution)
3	        Multi-user mode with networking, no GUI
4	        Unused / Custom
5	        Multi-user mode with networking and GUI
6	        Reboot the system

        cmd = init n (this command use for specific woek)

                     . .
                      .      n -> tends to 0 to 6 (Run Level)
